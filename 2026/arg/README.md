# ARG MVP v2.1：あなたが見つけるまで

## 起動
このフォルダで `python3 -m http.server 8000 --bind 127.0.0.1` を実行し、ブラウザで http://localhost:8000/ を開いてください。Python 3 が必要です。HTMLの直接ダブルクリックではなく、HTTP経由で遊んでください。

初回は記事一覧から。再プレイは http://localhost:8000/reset.html を開いて「最初から始める」を押します。旧版の進行とは別のキーで保存します。

画面に登場する人物・大学・コメント・閲覧者数は架空です。外部SNSや検索サービスには接続しません。復元・削除はゲーム内の演出で、配布ファイル自体は変更しません。状態と結末時刻はブラウザのlocalStorageに保存します。ブラウザでサイトデータの保存を許可してください。

## 作者用情報（ネタバレ）

前半は ARCHIVE CHECK → INDEX REPAIR → BLOCK CHECK と進みます。人物の名前を調べていること自体は隠しません。「既存のページを照合している」と思った行為が、91%で「本人が切り離した人物記録を再接続していた」と分かる反転です。生身の人間の蘇生を意味しません。

入口 → 古いHTML記事 → コメント → u_2046_11 → 保存ページ3件 → /1743/1106/ → 照合（68%） → 補完承認（83%） → 人物記録の判明（91%） → 日記 → 選択 → 結末 → 最初の記事。

URLは記事本文の「時刻4桁／月日4桁」と履歴の17:43・1106から導きます。HTMLソースを見る必要はありません。
入力：水原ユウ / 20（20歳・全角数字も可） / 東央大学。名前と主催校は学園祭、年齢は11月6日の紹介キャッシュから得られます。雨の記事は補強手掛かりで、全部読むことを進行条件にはしません。

最終選択には日本語で代償を表示。RESTOREは検索へ再登録し閲覧者が増加。PURGEは関連37件も削除。未選択で閉じる場合は結末を保存せず、再訪しても強制的には選択されません。結末確定後はブラウザの戻る等で選び直せないため、別の結末はテスト用リセットから確認してください。

今回はデータブロック表示を用い、旧版の人物形の画像代替図は撤去しました。実写素材や公開サービスへの接続は含みません。完全な初見評価には別のテスターによる検証が必要です。
